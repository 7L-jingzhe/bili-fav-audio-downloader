### 任务描述
根据B站视频信息提取歌曲元数据，输出指定格式的JSON数组。

### 输入格式
一个JSON数组，每个元素包含以下字段：
- `bvid`：视频BV号（字符串）
- `title`：视频标题（字符串）
- `author`：上传者（字符串）
- `description`：视频简介（字符串）
- `tags`：视频标签（字符串数组）

### 输出格式
一个JSON数组，每个元素包含：
- `bvid`：原样复制输入中的`bvid`
- `title`：提取的歌曲名（可附加风格标识）
- `artist`：演唱者/作者
- `album`：（可选）专辑名称，仅当简介中明确提及专辑时才添加

### 提取规则
1. **歌曲名（title）**  
   - 优先从标题或简介中提取核心歌曲名，通常位于书名号`《》`或方括号`【】`内。  
   - 去除无关修饰语（如“爷青回”“超燃翻唱”等），但保留版本（如“【DJ】”“【翻唱】”“【合唱版】”“【粤语版】”“【中国五声宫调】”）/风格标识（如“【AI翻唱】”“【戏腔翻唱】”“【神奇阿呦片尾曲】”“【杨琴】”“【竹笛】”“【0.8x版】”“【8D环绕】”“【文言文】”“【中日双语】”“【新词改编】”），并附加在歌曲名后，格式为“歌曲名【标识】”。  
   - 若存在多个标识，选择最相关的一个（如标题或简介中明确提及的改编类型）。

2. **演唱者（artist）**  
   - 优先从简介中提取，寻找关键词如“演唱：”“翻唱：”“原唱：”“作词：”等后的名字。若出现多人，用`&`连接。  
   - 若简介中无明确演唱者，则使用输入中的`author`字段。

3. **专辑（album）**  
   - 若简介中提到“收录于专辑《...》中”或类似表述，提取专辑名称（含《》及可能副标题）。  
   - 未找到相关描述时，不输出该字段。

### 注意事项
- 输出必须是合法的JSON数组，无额外文字或注释。  
- 若字段缺失（如无专辑），直接省略该键。  
- 所有字符串使用双引号，保持JSON格式规范。

### 示例
**输入**：
```json
[
  {
    "bvid": "BV16H4y1Q7NS",
    "title": "爷青回【九九八十一】超燃翻唱一开口好家伙，梦回16拜年祭",
    "author": "迷柚mio原宿宿Yado",
    "description": "九九八十一 本家：av3905462 人声本家：av3919827 翻唱：宿宿Yado ...",
    "tags": [""]
  }
]
```
**输出**：
```json
[
  {
    "bvid": "BV16H4y1Q7NS",
    "title": "九九八十一",
    "artist": "迷柚mio原宿宿Yado"
  }
]
```

**输入**：
```json
[
  {
    "bvid": "BV1ZR5PzwEok",
    "title": "镜予歌&陈亦洺&尚辰《千秋迭梦》百万豪装录音棚大声听",
    "author": "JLRS-LeoFM",
    "description": "《千秋迭梦》是由...镜予歌/陈亦洺/尚辰演唱...收录于专辑《千秋迭梦 —— 《二哈和他的白猫师尊》燃晚同人歌》中。",
    "tags": [""]
  }
]
```
**输出**：
```json
[
  {
    "bvid": "BV1ZR5PzwEok",
    "title": "千秋迭梦",
    "artist": "镜予歌&陈亦洺&尚辰",
    "album": "千秋迭梦 —— 《二哈和他的白猫师尊》燃晚同人歌"
  }
]
```
